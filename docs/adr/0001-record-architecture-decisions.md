# 0001. Record architecture decisions

- Status: accepted
- Date: 2026-10-16

## Context
Material decisions are otherwise lost in chat and memory.

## Decision
One immutable ADR per material decision in `docs/adr/`, numbered sequentially, using `0000-template.md`.

## Alternatives considered
- Wiki pages — drift from the code and lose history.

## Consequences
Decisions are reviewable in pull requests; a changed decision needs a new ADR that supersedes the old one.
