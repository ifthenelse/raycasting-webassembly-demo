WebAssembly Raycaster in Rust

This is a Wolfenstein-style raycasting engine written in Rust and compiled to WebAssembly with wasm-bindgen. It renders textured walls, floors, ceilings, a skybox and sprites on the CPU at 320×200, then copies the frame to a canvas. Click the game view above to focus it and start moving.

Controls

  • W / ↑ move forward, S / ↓ move back
  • A / ← turn left, D / → turn right
  • , / . strafe left / right
  • Space jump, hold Shift to walk
  • M generate a new random map

Features

  • Textured raycasting for walls, floors, ceilings and a skybox
  • Sprites that pick a frame from the viewing angle, as in Duke Nukem 3D
  • Wall lamps placed automatically on generated maps
  • Movement with wall sliding and jump physics
  • Procedural maps with random walls and ceiling sections
  • A debug panel with a top-down map and the player position

How does a raycaster work?

A raycaster casts one ray per screen column across a 2D grid map. A DDA grid walk finds the nearest wall the ray hits. The engine then draws a vertical slice whose height is inversely proportional to the fish-eye-corrected distance. Floors and ceilings are drawn row by row, and sprites are sorted by depth and clipped against the wall depth buffer.

Why Rust and WebAssembly?

The per-pixel inner loops run as compiled WebAssembly instead of JavaScript. Rust writes every pixel into a shared RGBA framebuffer in WASM linear memory. JavaScript uploads the textures once and copies the framebuffer to the canvas each frame. There is no WebGL and no GPU code.
